## Bundled in the application

### Natural Earth — map geometry

`src/data/japan-map.json` is generated by `scripts/build_map_data.py` from:

- **Natural Earth 1:10m Cultural Vectors** — `ne_10m_admin_1_states_provinces`
  and `ne_10m_admin_0_countries`
- Source: <https://www.naturalearthdata.com/>
- **Licence: public domain.** Natural Earth states: "All versions of Natural
  Earth raster and vector map data… are in the public domain. … No permission is
  needed to use Natural Earth. Crediting the authors is unnecessary."

The data has been simplified (Douglas–Peucker) and clipped to a Japan-centred
bounding box for display. YureWatch credits Natural Earth on the map regardless,
because provenance is useful to readers.

### Earthquake, EEW and tsunami information

Displayed data is retrieved at runtime from the **P2P地震情報 JSON API v2**
(<https://www.p2pquake.net/>), which relays information published by the
**Japan Meteorological Agency (気象庁, JMA)**. It is not bundled with, cached by,
or redistributed with this application. Use is subject to:

- P2P地震情報 利用規約 / 二次利用 terms — <https://www.p2pquake.net/secondary_use/>
  ("商用・非商用問わずご利用いただけます")
- JMA content terms — <https://www.jma.go.jp/jma/kishou/info/coment.html>
  (Japanese government standard terms for public data; attribution to JMA is
  displayed in the app's source panels)

YureWatch is not affiliated with, endorsed by, or operated by JMA, NIED, or
P2P地震情報.

## Fonts

No font files are bundled. The UI uses the platform's system font stack
(`Hiragino Sans`, `Noto Sans JP`, `Yu Gothic UI`, `Meiryo`, `system-ui`), so text
rendering follows the device and carries no redistribution obligation.

## Audio

The EEW alert tone is synthesised at runtime with the Web Audio API. No recorded
audio, and specifically no broadcast or third-party alert jingle, is included.
