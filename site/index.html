YureWatch

A map-centric, informational viewer for earthquakes, Earthquake Early Warnings (緊急地震速報 / EEW) and tsunami forecasts (津波予報) across Japan. It shows what the Japan Meteorological Agency has published — on a map, in Japanese or English — and is explicit about what it does not know.

Open Live Viewer → Download Android APK Release history

The viewer runs entirely in your browser — no backend, no account, no analytics. Runs on desktop and mobile.

What this is, and what it is not

Informational only — not a safety device

YureWatch is a viewer. It displays earthquake and warning information published by the Japan Meteorological Agency (気象庁) and relayed by P2P地震情報. It does not predict earthquakes, it does not detect earthquakes independently, and it cannot guarantee that a warning reaches you before shaking starts.

  • EEW estimates carry error and are revised; false alarms occur.
  • 予報 (forecast) and 警報 (warning) are different things — the app labels them differently.
  • Communication delays and outages mean information may not arrive at all.
  • For anything that matters, follow 気象庁の発表 and the instructions of your local authorities.

Features

One codebase and one build produce the Android app, this website's viewer, and the APK.

  • Earthquake information

    Recent 地震情報 plotted by epicentre with observed 震度 by prefecture. Revisions (震度速報 → 震源情報 → 各地の震度) are merged into one event rather than listed as duplicates.

  • Earthquake Early Warning

    緊急地震速報 with warning areas, predicted intensity, serial-numbered revisions and cancellations. 警報 and 予報 are labelled differently.

  • Tsunami bulletins

    津波予報 with JMA forecast regions shaded by grade (大津波警報 / 津波警報 / 津波注意報), plus advisory and non-effective grades.

  • Map navigation

    Pan and zoom a self-contained vector basemap of Japan. No map tiles, no tile server, no API key — the geometry ships inside the app.

  • Diagnostics & honest state

    Live, degraded, stale and offline are distinct states. Missing values stay missing: an unknown depth is never drawn as zero.

  • Japanese and English

    Full translation both ways, switchable from the header and remembered. Times are always rendered in JST regardless of device timezone.

Known limitations

Stated plainly rather than hidden.

Known limitations
Limitation Consequence
Polling, not push Data is fetched from /history every 6–20 s, so a warning can arrive later than it would over the provider's WebSocket.
警報 only for EEW The public relay forwards 緊急地震速報（警報）; lower-grade 予報 content is not distributed through it.
No measured tsunami heights Only 津波予報 (forecasts) are shown, not observed wave heights.
NIED real-time intensity not connected Station-level 震度 comes from JMA bulletins, not the NIED real-time feed.
Third-party relay P2P地震情報 is an unpaid, unwarranted service with no availability guarantee. If it is down, YureWatch says so instead of showing stale data as current.
Browser speech depends on the platform Voice announcements need a system TTS voice for the active language; the viewer reports honestly when none is installed.

Build it yourself

Node 20+ and Python 3 are required. There is no backend to configure and no API key to obtain — the feed is anonymous. 

git clone https://github.com/franzathome2024-hue/yurewatch.git
cd yurewatch
npm ci

npm run dev        # local dev server
npm test           # unit + integration tests
npm run build      # single-file bundle -> dist/yurewatch.html
npm run site:build # assemble this website + viewer -> _site/
bash tools/build-apk.sh   # Android APK (needs the Android SDK)

The website is this landing page plus dist/yurewatch.html copied to viewer/index.html. One application, one build, three targets — Android, web, and this page.
